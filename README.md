# Theo's Sydney

A quest map of Sydney from the Coven & Co.

⬆️ Back to the Theo folder: [INDEX](../INDEX.md)

- **index.html** — Theo's map (the link to send her)
- **coven.html** — the Coven's page: sign in, add spots, write spells, make quests, read Theo's notes back
- **app.js** — the code for both pages
- **app.css** — the look
- **config.js** — settings: Supabase address + publishable key, WhatsApp link, welcome letter
- **mapdata.js** — Sydney coastline (© OpenStreetMap contributors) + a backup copy of the spots, made by `build/build.py`

Tip: add `#reset` to the end of the map link to clear the saved progress on that phone (for testing).
